# 體態追蹤操作手冊 — 專案說明

## 專案概述

Dr.Li 科學體重管理課程的學員專屬教材，為單頁靜態 HTML 網頁，部署於 GitHub Pages。

**檔案**：`教材.html`（唯一主檔）

## 頁面內容

| 章節 | 重點 |
|------|------|
| BA 照拍攝指南 | 拍攝姿勢、角度、光線等注意事項，搭配範例照片 `拍攝BA照1.jpg`／`拍攝BA照2.jpg` |
| 體態圍度量測 | 各部位圍度量測方法，搭配範例照片 `體態量測.jpg` |

## Header / `<head>` 標準設定（已套用）

- 已依主網站 CLAUDE.md 規範套用標準 `page-header` / `brand-bar` header 結構與樣式。
- **Favicon**：`logo.jpg` 轉 Base64 data URL 內嵌。
- **Title**：`Dr. Li 科學體重管理師-體態追蹤操作手冊`。

## 目錄結構

```
體態追蹤操作手冊/
├── 教材.html          主檔
├── 拍攝BA照1.jpg       BA 照拍攝範例
├── 拍攝BA照2.jpg       BA 照拍攝範例
└── 體態量測.jpg         圍度量測範例
```

## 技術架構

- **純 HTML + CSS**，無外部 JS 框架
- 字型：Google Fonts（Noto Sans TC + Inter）
- 色彩系統：CSS 自訂屬性定義於 `:root`（`--primary`、`--accent` 等，與主網站色彩系統一致）

## 修改注意事項

- 教材**不會在主網站產生任何連結**，由 Dr. Li 直接傳送給學員
- 本目錄為獨立子專案，**不隸屬** `體重管理師網站/` 主網站，修改時以本目錄為範圍，不要互相引用或牽連
- 範例照片若更新，需確認 `教材.html` 內對應 `<img>` 路徑同步更新

## 部署與 GitHub

| 項目 | 資訊 |
|------|------|
| Git root | `體重管理師網站/`（本目錄為其子目錄） |
| 分支 | `master` |
| 同步規則 | 改完立即 `git add` + `commit` + `push`，不需詢問（GitHub Pages 由 `master` 根目錄自動建置） |
